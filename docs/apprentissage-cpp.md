# Parcours d'apprentissage C++

## Objectif
Apprendre le C++ en construisant progressivement les outils et composants nécessaires à un émulateur. Comprendre le code et savoir le déboguer, pas seulement mémoriser des exemples.

## Niveau 1 — Fondamentaux
- [ ] Types : `int`, `float`, `bool`, `char`, `std::string`.
- [x] Variables et constantes.
- [x] Opérateurs.
- [x] Conditions : `if`, `else`, `switch`.
- [x] Boucles : `for`, `while`.
- [x] Fonctions et paramètres.
- [x] Valeurs de retour.

## Niveau 2 — Données et structures
- [x] Tableaux et `std::array`.
- [x] `std::vector`.
- [x] `enum class`.
- [x] `struct`.
- [x] Classes et objets.
- [x] Encapsulation.
- [x] Références et pointeurs.

## Niveau 3 — C++ moderne
- [x] `const` et `constexpr`.
- [ ] Durée de vie des objets.
- [ ] RAII.
- [ ] Smart pointers.
- [ ] `std::optional`.
- [ ] Gestion des erreurs. (vu : `try`/`catch` sur `std::out_of_range`)
- [ ] Templates de base.

## Niveau 4 — Système et performance
- [ ] Fichiers binaires.
- [x] Endianness.
- [x] Bits et masques binaires.
- [ ] Alignement mémoire.
- [ ] Threads et synchronisation.
- [ ] Profilage.
- [ ] Optimisation mesurée.

## Méthode
1. Lire une explication courte.
2. Étudier un exemple.
3. Écrire une variante soi-même.
4. Compiler et tester.
5. Déboguer.
6. Expliquer avec ses propres mots.
7. Noter les acquis et les questions.
